{{- /* Markdown image render hook. Adds the three attributes an image-heavy post needs and markdown cannot express: loading="lazy" a 55-image post is ~32MB -- about 90 seconds of 720p video -- and without this every image is fetched on load whether or not the reader ever scrolls. width/height NOT the display size. CSS drives the actual width; the browser uses only the RATIO of these two to reserve correctly-shaped space before the bytes arrive. Omitting them makes lazy loading actively worse than none: unsized images collapse to zero height and the page jumps as each one lands. decoding="async" keeps image decode off the main thread. Dimensions are read from the file rather than assumed, because assuming is wrong often enough to matter -- on the wedding post roughly a fifth of the images are neither 3:2 nor 2:3 (crops, a 2.06:1 panorama, 4:3 phone shots). If Hugo cannot read a given format the attributes are simply omitted, which is no worse than before. NOTE: this lives in the theme, not in a site's layouts/, because poohbot sets contentDir = "." -- so a site-level layouts/ is inside the content dir and Hugo tries to parse these files as content ("unmarshal failed: invalid character '{'"). The theme directory is in that site's ignoreFiles, so it is safe here. */ -}} {{- /* A trailing #size names a display width: ![alt](../img/x.avif#half). Markdown has no way to express one, and dropping to a raw to get it would lose everything above -- the real width/height and the lazy loading -- which is a bad trade for a styling tweak. Same idea as the `featured: ...#top30` convention in front matter. The fragment MUST come off before resources.Get: it would otherwise miss, and a miss here means no dimensions, which is exactly the case this hook exists to prevent. Anything unrecognised is ignored rather than guessed at. */ -}} {{- $src := .Destination -}} {{- $size := "" -}} {{- if strings.Contains $src "#" -}} {{- $bits := split $src "#" -}} {{- $src = index $bits 0 -}} {{- $frag := index $bits 1 -}} {{- if in (slice "half" "two-thirds" "third" "quarter") $frag -}} {{- $size = printf "size-%s" $frag -}} {{- end -}} {{- end -}} {{- /* content pages sit one level down, so their image paths start ../ */ -}} {{- $rel := strings.TrimPrefix "../" $src -}} {{- $res := resources.Get $rel -}} {{- $w := 0 -}} {{- $h := 0 -}} {{- /* .Width EXISTS only on image resources. Hugo does not classify AVIF as one (Go has no AVIF decoder), and calling .Width on a non-image resource is a hard build error, not an empty value -- so the type must be checked first. */ -}} {{- if and $res (eq $res.ResourceType "image") -}} {{- $w = $res.Width -}} {{- $h = $res.Height -}} {{- end -}}
